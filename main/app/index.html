PERSONALIZATION

个性化在产品里，到底改变了什么？What does personalization actually change?

不是换一个皮肤、调一种语气。同一份材料，不同的学习者会得到结构、节奏、反馈和挑战强度都不同的学习过程。Not a new skin or a different tone. The same material becomes a genuinely different learning process — in structure, pace, feedback, and challenge.

🧭

结构Structure

有人需要先看到清晰的路线和检查点，有人更适合先从例子进入概念。Some need a clear roadmap with checkpoints first; others learn best by entering through examples.

同一份讲义 → 路线图先行，或例题先行Same handout → roadmap first, or example first
⏱️

节奏Pace

需要更多支架时，内容拆得更细；已经熟悉时，减少不必要的停顿。When you need more scaffolding, content is sliced finer; when you're fluent, it skips the pauses.

同一个知识点 → 五步小切，或一步直达Same concept → five small steps, or one direct leap
💬

反馈Feedback

有人需要更温和、确定的反馈，有人更喜欢直接指出问题所在。Some need gentle, reassuring feedback; others prefer the problem pointed out directly.

同一次答错 → 鼓励式引导，或直给式辨析Same wrong answer → encouraging guidance, or direct analysis
🎯

挑战Challenge

系统可以先给线索、拆成步骤，也可以增加主动回忆和自我测试。The system can offer hints and steps first — or dial up active recall and self-testing.

同一轮练习 → 提示阶梯，或迁移挑战Same practice set → hint ladder, or transfer challenge
